PING PONG - Proyecto Android

OPCION A: Android Studio
1. Descomprime y abre la carpeta con File > Open.
2. Espera la sincronizacion de Gradle.
3. Build > Build APK(s). El archivo queda en app/build/outputs/apk/debug/app-debug.apk

OPCION B: GitHub (sin instalar nada)
1. Crea un repositorio nuevo y sube todo el contenido de esta carpeta (incluida .github).
2. En la pestana Actions se ejecuta "Build APK" solo.
3. Descarga el artefacto PingPong-apk, descomprimelo e instala app-debug.apk en tu Android
   (permite "instalar apps de origen desconocido").
